# DragonTower

**Play now → https://thebabeldragon.github.io/DragonTower/**

One more attempt. One more floor. Don't fall.

A tiny dragon climbs an endless seeded tower. Miss a platform and the
whole climb is lost. Play it in the browser, no install.

**Controls:** Arrow keys / A D to move, Space to jump (hold for a
higher jump). On phones, use the on-screen buttons.

Single-file HTML5 canvas game, deployed with GitHub Pages.
All tuning lives in the `CFG` object at the top of the script.
